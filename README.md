# Marketing Skills

Repositório-oficina para trabalho de **marketing** com o Claude Code. Abra uma sessão (claude.ai/code ou local) com este repositório selecionado e o Claude descobre automaticamente as skills em `.claude/skills/`.

Curadoria de [alirezarezvani/claude-skills](https://github.com/alirezarezvani/claude-skills) (licença MIT, ver `LICENSE-claude-skills`), copiada do commit `27cfcd0`.

## Como atualizar

Copie de novo as pastas correspondentes do repositório de origem (`marketing-skill/skills/*`, `marketing-skill/video-content-strategist/skills/*`, `marketing/linkedin/skills/*`, `marketing/landing/skills/landing`) para `.claude/skills/`.

Só as skills foram copiadas; agentes e slash commands dos plugins originais não fazem parte deste repositório.
